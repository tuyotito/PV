# Phrasal verbs

Application web pour apprendre 1000 phrasal verbs anglais.

- 1000 verbes avec traduction française et phrase d’exemple (anglais + français)
- Trois modes : cartes, quiz, liste
- Deux sens : anglais → français et français → anglais
- Progression enregistrée dans le navigateur (localStorage)
- Un seul fichier, sans dépendance (`index.html`)

## Utiliser en ligne (GitHub Pages)

1. Dans le dépôt : **Settings → Pages**
2. Source : **Deploy from a branch**, branche `main`, dossier `/ (root)`
3. L’adresse sera `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`

## Utiliser sur téléphone

Ouvre l’adresse Pages sur ton téléphone, puis « Ajouter à l’écran d’accueil ».
